      Controls

      Camera

      • WASD / arrows — move
      • Mouse wheel — zoom at cursor
      • Middle drag or Space + drag — pan
      • F fit network · 0 reset view

      Graph mode 1

      • Click empty space — add node (links to selection)
      • Click a road — split it with a new node (Shift to skip)
      • Click node — select / connect · drag — move
      • Right click — deselect, or delete hovered node/edge
      • Del delete selected node · Esc deselect

      Roads mode 2

      • Click a road to select it
      • +/− lanes · O one-way · R reverse
      • Panel: road type, speed limit, pedestrian crossing
      • Click a junction node to choose lights / stop / yield

      Drive mode 3

      • ↑/W throttle · ↓/S brake, then reverse
      • ←→/AD steer · Space handbrake
      • R reset car · mouse wheel zoom

      Simulation

      • T traffic · [/] fewer / more vehicles
      • M physics model · Y dry / wet / icy road
      • C collision debug · X traffic routes · L lanes
      • N ghost (no collisions) · P pause

      Train mode 4

      • Pick a course (or the whole curriculum) and press Start
      • [/] slower / faster · Z rendering on/off · P pause
      • K (drive mode) autopilot: the champion drives your car

      Navigate mode 5

      • Click a road for START, another for DESTINATION
      • Choose A* / Dijkstra and fastest / shortest
      • Drive autonomously: watch each layer decide

      Sensors

      • I sensor panel and sensor views on the map
      • U cycle perfect / realistic / degraded sensors

      Debug

      • F3 stats · B geometry · V skeleton
      • G snap · Shift+G grid · H this help

      Your network is saved in this browser automatically.
